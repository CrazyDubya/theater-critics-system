# theater-critics-system

The name is wrong. This repository contains the **prison** project, not a theater critics system.

## What's actually here

- `prison/` — a multi-agent simulation with an `eternal_lockdown/` scenario and an AutoGen integration. See `prison/README.md`, `prison/QUICK_START.md` and `prison/PROJECT_STATUS.md`, which are the real documentation.
- `prison/EXPERIMENT_ollama-integration.md` — notes on running the simulation against local models.
- `git-organization-strategy.md` — a copy of the same file that lives in `git-managed` and `git-workflow-project`.

## Before you use this

The theater critics work is in `theater-critics`. A separate `prison-simulation` repository also exists. This repository should either be renamed to match its contents or its contents folded into `prison-simulation` and the repository deleted — right now it is 214 MB filed under a name that will send you to the wrong place.
